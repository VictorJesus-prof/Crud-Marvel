# CrudMarvel

Sistema web para cadastro e gerenciamento de personagens e filmes do universo Marvel, desenvolvido como projeto prático durante o curso Técnico em Desenvolvimento de Sistemas (IFPR).

O sistema permite cadastrar, visualizar, editar e excluir personagens e filmes, com os dados armazenados em um banco de dados MySQL e apresentados dinamicamente em tabelas.

## 📋 Funcionalidades

### Personagens

* Cadastro de personagens com:

  * Imagem
  * Nome
  * Poder
  * Tipo (Herói, Anti-Herói ou Vilão)
  * Filme relacionado
* Listagem de personagens
* Edição de personagens cadastrados
* Exclusão de personagens

### Filmes

* Cadastro de filmes com:

  * Capa
  * Título
  * Ano de lançamento
  * Duração
  * Nota
* Listagem de filmes
* Edição de filmes cadastrados
* Exclusão de filmes

### Sistema

* Menu inicial para acesso aos cadastros
* Relacionamento entre personagens, tipos e filmes
* Confirmação antes da exclusão de registros
* Organização do projeto em camadas

## 🛠️ Tecnologias utilizadas

* PHP
* HTML5
* CSS3
* Bootstrap 5
* MySQL
* PDO
